媒体批量下载器

输入用户主页或单条链接，扫描图片 / 视频 / GIF，勾选后批量下载到本机
走代理访问外网媒体（如 clash/v2ray 的 HTTP 端口）
代理填本地代理软件的 HTTP/SOCKS 地址即可（如 clash 7890）。
Twitter 用户首页用"会话直连"（设置里填 auth_token / ct0，浏览器登录 x.com 后 F12→Application→Cookies 复制）；Bluesky / YouTube / 单条推文不需要。
